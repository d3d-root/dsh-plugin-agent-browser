# Установка «Браузера агента» в DeepSeek Harness

Подробная инструкция на случай, если что-то пошло не так. Краткая версия —
в [README](../README.md#установка).

---

## Что нужно

- **DeepSeek Harness** — приложение (Electron). В обычном браузере плагин
  честно скажет, что браузер доступен только в приложении: `<webview>` — это
  часть Electron.
- Больше **ничего**. Node, Chrome, Playwright и прочее не нужны: Chromium уже
  внутри DSH.

---

## Способ 1: через список плагинов (проще всего)

1. Откройте DSH.
2. В левой панели нажмите **Plugins** (или **Settings → Plugins**).
3. Нажмите **Add plugin**.
4. Вставьте адрес репозитория:

   ```
   https://github.com/d3d-root/dsh-plugin-agent-browser
   ```

5. Дождитесь установки. Плагин появится в списке с переключателем.
6. **Включите** переключатель.
7. **Полностью перезапустите DSH** — не просто закройте окно, а выйдите из
   приложения и запустите заново.

После перезапуска в правой панели появится вкладка «Браузер агента», а у агента
— 22 инструмента `browser_*`.

---

## Способ 2: из папки

Если репозиторий уже скачан:

1. **Plugins → Add plugin** → выберите **абсолютный путь** к папке
   `dsh-plugin-agent-browser`.
2. Включите плагин и перезапустите DSH.

---

## Способ 3: вручную, через терминал

Нужен `pnpm`. Он лежит внутри DSH:

```powershell
$Dsh = "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"

& $Dsh plugin --profile desktop add "github:d3d-root/dsh-plugin-agent-browser"
```

Затем добавьте `dsh-plugin-agent-browser` в `dsh.profile.bundles` файла
`%USERPROFILE%\.dsh\profiles\desktop\package.json` и перезапустите DSH.

> Профиль может называться иначе: посмотрите папки в `%USERPROFILE%\.dsh\profiles\`.

---

## Почему нужен полный перезапуск

Плагин состоит из двух половин:

| Половина | Где живёт | Как загружается |
|---|---|---|
| серверная (`lib/index.js`) | процесс DSH | подхватывается на лету |
| клиентская (`lib/client.js`) | окно приложения | только при загрузке страницы |

Если включить плагин в уже открытом окне, серверная половина заработает сразу,
а клиентской в нём ещё нет. Поэтому нужен перезапуск.

**Плагин сам об этом скажет.** Через 7 секунд после загрузки окна, если
клиентская половина не отметилась, в правом нижнем углу появляется баннер:

```
┌─────────────────────────────────────────────┐
│ Браузер агента              [Перезагрузить] │
│ Плагин включён, но окно открыто со старой    │
│ сборкой. Нажмите «Перезагрузить», чтобы      │
│ браузер заработал.                           │
└─────────────────────────────────────────────┘
```

Кнопка делает `location.reload()`. Иногда этого достаточно; если нет — полный
перезапуск приложения.

Инструмент `browser_status` тоже диагностирует это состояние и прямо пишет,
что делать.

## Проверка, что всё работает

Попросите агента:

> открой example.com и покажи заголовок страницы

Ожидаемый ответ: «Открыто: https://example.com/ · Заголовок: Example Domain»,
а справа появится вкладка с сайтом.

Или проверьте сами, без агента: откройте правую панель → «Браузер агента» →
введите адрес в строку.

### Журнал

```
%TEMP%\dsh-agent-browser.log
```

Что должно быть:

```
[info] apply() начат, протокол 2, язык ru
[info] зарегистрировано инструментов: 22
[info] мост готов: http://127.0.0.1:<порт>/dsh-agent-browser
[info] клиент подключён: окон 1
```

Последняя строка — главная: она означает, что обе половины на связи.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Вкладки нет, в журнале нет `клиент подключён` | плагин включён после запуска — перезапустите DSH |
| Баннер «окно открыто со старой сборкой» | нажмите «Перезагрузить», при неудаче — полный перезапуск |
| «клиентская половина не загружена» от инструментов | то же самое |
| «браузер доступен только в приложении DSH» | открыто в браузере, а не в приложении |
| «в этой сессии браузер не открыт» | вызовите `browser_open` |
| `транспорт не поднялся` | порт занят — задайте `port: 0` в настройках плагина |
| Ничего не помогло | удалите плагин, перезапустите DSH, поставьте заново |

Логи DSH с ошибками запуска лежат здесь:

```
%APPDATA%\@deepseek-ai\dsh-desktop\logs\
```

## Обновление

**Plugins →** у плагина нажмите обновление (или удалите и поставьте заново).
После обновления — полный перезапуск.

При обновлении с версии ниже 1.0.1 ничего переносить не нужно: настройки в
`cordis.patch.yml` плагина перезаписываются только при установке.

---

## Удаление

**Plugins →** выключите переключатель, затем удалите плагин. Перезапустите DSH.

Если ставили вручную, удалите зависимость и запись из `dsh.profile.bundles`:

```powershell
$Dsh = "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"
& $Dsh plugin --profile desktop remove dsh-plugin-agent-browser
```

Вкладка браузера исчезнет, профили Chromium удалятся вместе с процессом.

## Частые вопросы

**Нужен ли интернет?** Да, для сайтов. Сам плагин работает локально.

**Куда попадают скриншоты?** В `%TEMP%\dsh-agent-browser\`. Инструмент может
сохранить и в рабочий каталог чата — но не куда угодно.

**Видит ли агент мои cookie?** Только cookie того профиля, который создан для
этого чата. Ваш повседневный браузер и другие чаты изолированы.

**Сколько браузеров можно открыть?** По одному на чат, без жёсткого предела.
Каждый — отдельный процесс Chromium, поэтому десяток одновременно заметно
съест память.

**Можно ли работать в одном браузере с агентом?** Да, в этом и смысл: вы и
агент смотрите на одну страницу. Если вы уведёте страницу в сторону, агент
увидит уже её.
