## [1.0.2] — 2026-11-07

### Добавлено

- **Публикация в npm и авто-выпуск без токенов.** `.github/workflows/publish.yml`
  публикует пакет по тегу `v*` через Trusted Publishing (OIDC): GitHub выдаёт
  короткоживущий токен на один запуск, npm проверяет его по доверенному
  издателю. Долгоживущих секретов в репозитории нет. Перед публикацией workflow
  сверяет тег с версией в `package.json` и прогоняет тесты, а публикует с
  `--provenance` — пользователь видит, из какого коммита собран пакет.
  Установка из реестра включает кнопку обновления в DSH.
- `prepublishOnly` прогоняет тесты перед публикацией.
- `browser_status` показывает версию плагина — первый вопрос при разборе
  проблем, особенно у установок из Git, где кнопки обновления в интерфейсе нет.
- Версия плагина пишется в журнал при старте.
- `docs/install.md`: разделы «Обновление» и «Как перейти с GitHub на npm».
- `docs/publishing.md`: разовая настройка npm и выпуск по тегу.
- `CHANGELOG.md`.

### Исправлено

- Подсказки больше не обещают, что `Ctrl+R` решит проблему рассинхрона половин:
  Electron может отдать ту же закэшированную сборку. Везде, включая баннер,
  главный совет — перезапустить приложение целиком.

## [1.0.1] — 2026-11-07

### Добавлено

- **Сторож в `index.html`.** Через 7 секунд после загрузки окна проверяет,
  загрузилась ли клиентская половина. Если нет — показывает баннер с кнопкой
  «Перезагрузить» и советом перезапустить приложение. Работает даже когда кода
  плагина в странице ещё нет.
- **Эндпоинт `/bootstrap`.** Клиент забирает токен моста сам, если не нашёл его
  во вставке `index.html`. Это снимает целый класс поломок: раньше клиент
  молча получал 403 и выглядел как «плагин не загрузился».
- Тесты на `/bootstrap`: защита от DNS-rebinding по `Host` и от межсайтового
  запроса по `Sec-Fetch-Site`.

### Исправлено

- **Регистрации обёрнуты в `ctx.effect`.** Без этого горячая перезагрузка
  плагина падала на конфликте идентификаторов, и вкладка исчезала до перезапуска
  окна.
- **Редирект больше не считается ошибкой.** `loadURL` отвергает промис с
  `ERR_ABORTED (-3)` при редиректе, хотя навигация удалась. Теперь судьбу
  перехода решают события `webview`, а отмена игнорируется.
- Вставка в `index.html` регистрируется синхронно и повторяется до 20 раз,
  независимо от готовности транспорта.

## [1.0.0] — 2026-11-07

Первый публичный выпуск.

### Возможности

- Настоящий Chromium в правой панели DSH через `<webview>`: нативная прокрутка,
  ввод, клики. Не headless и не трансляция картинки.
- **Один чат — один браузер.** Профили изолированы: разные cookie, разные
  логины, независимые сессии.
- **Несколько агентов одновременно.** Инструмент адресуется сессии своего
  агента, поэтому агенты не перехватывают команды друг друга.
- 22 инструмента: навигация, чтение, HTML, `eval`, клики (включая настоящие
  события мыши), ввод, клавиши, прокрутка, скриншоты, перетаскивание, смена UA.
- Решение капч: настоящие события мыши Chromium и «человеческая» траектория
  перетаскивания для слайдер-пазлов.
- Установка одним кликом из списка плагинов: оформлен как бандл
  (`dsh.bundle.patch`).

### Безопасность

- Транспорт только на loopback; токен обязателен и передаётся в заголовке.
- `Access-Control-Allow-Origin: null` вместо `*`.
- Ограничение тела запроса 8 МБ.
- Скриншоты пишутся только в свой каталог и рабочий каталог чата.
- Экранирование `</script>` во вставке в `index.html`.
